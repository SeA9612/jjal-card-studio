# 짤·카드 스튜디오 · FRAME

로그인 없이 PNG·JPEG와 문구로 밈·카드·SNS용 이미지를 만드는 브라우저 편집기입니다.

- 사이트: https://SeA9612.github.io/jjal-card-studio/
- 소스: https://github.com/SeA9612/jjal-card-studio

## 주요 기능

- PNG·JPEG 실제 파일 형식 검사, 업로드 오류 시 기존 작업 보존
- 한글·영문·이모지·줄바꿈, 위치·크기·색·글꼴·정렬 편집
- 1:1, 4:5, 9:16 미리보기와 같은 렌더링으로 PNG 다운로드
- 긴 문구 자동 크기 조절, 영역을 넘으면 다운로드 전 안내
- 이미지·출처를 포함한 사용자 템플릿 생성·불러오기·수정·삭제
- IndexedDB로 템플릿과 현재 작업을 브라우저에 보관
- 전체 검증 후 적용하는 JSON 백업·복원

## 데이터와 이미지

이미지 편집은 브라우저 안에서 처리되며 서버로 업로드하지 않습니다. 업로드 이미지는 최대 1600px로 재인코딩하며 원본 메타데이터를 복사하지 않습니다. 브라우저 데이터를 삭제하면 저장된 작업도 삭제되므로 JSON 백업을 권장합니다. 외부 이미지는 원본 URL과 사용 허가 근거를 기록해야 합니다. 개인정보나 비밀값을 이미지·문구·출처에 넣지 마세요.

기본 배경은 이 프로젝트에서 코드로 구성한 도형입니다. 마플의 상단 도구 모음·작업 영역·설정 패널 구조를 참고했으며, 마플의 로고·상품 사진·디자인 자산은 사용하지 않았습니다.

## 실행과 검사

별도 설치나 빌드가 필요하지 않습니다. 프로젝트 폴더에서 `python -m http.server 4173`을 실행하고 `http://localhost:4173`을 여세요. 파일을 직접 열지 말고 HTTP 서버를 사용하세요.

핵심 데이터 검사는 `node --test tests/*.test.js`로 실행합니다. 실제 브라우저 검증 결과와 아직 확인하지 않은 항목은 [검사 기록](./QA.md)에 구분해 기록합니다.

## 짧은 확인 방법

1. 위치: 위 공개 사이트의 편집기를 엽니다.
2. 행동: 문구 변경 → 화면비 선택 → PNG 다운로드 (3단계).
3. 통과 모습: 변경한 문구와 비율이 미리보기·저장 파일에서 같고 파일이 정상적으로 열립니다.
4. 안 될 때 모습: 잘못된 파일·JSON은 오류 이유를 안내하며 기존 편집·템플릿이 유지됩니다.

## AI와 본인 판단

- AI에게 맡긴 일: 편집기 구현, 오류 처리, 저장·복원 기능과 검사 초안 작성.
- 본인이 직접 판단한 일: 차콜 작업실 디자인 선택, 마플의 편집 구조 참고 요청, GitHub 연결 방식과 저장소 이름 선택.
- AI 제안을 따르지 않은 일: 초기의 단순한 시안에서 더 풍부한 편집 화면을 요청했습니다. 최종 제출 전 실제 사용 경험을 바탕으로 본인이 검토·수정할 수 있습니다.

## 현재 한계

브라우저와 기기 사이의 자동 동기화는 제공하지 않습니다. JSON으로 옮길 수 있습니다. 출처의 라이선스 유효성, 문구에 담긴 개인정보·비밀값은 자동 판정하지 않습니다. 공개하기 전 사용자가 실제 내용을 확인해야 합니다.
